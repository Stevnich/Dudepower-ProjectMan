# Membuat Medata Proyek

## 1. Fungsi

Medata ini digunakan agar projek dapat dibaca oleh **Software** dengan benar, dan menjadi induk dari folder projek.


---

## 2. Aturan dan Struktur File Medata

Ekstensi yang digunakan adalah **SQLite Database** **(.db**) yang dapat digunakan untuk menampung banyak properti, dan paling optimal untuk kedua OS, serta sulit untuk didekripsi manual

> **PENTING:** Ini adalah file pemimpon dalam setiap folder projek dimana software akan membaca seluruh data dari sini dan pastikan semua eksistensi file. Jika folder dalam proyek tidak memiliki file ini atau isi didalamnya tidak valid (seperti korup atau format tidak sesuai), software akan anggap proyek ini tidak pernah ada, tidak dimuat kedalam daftar proyek dalam studio.

* **Struktur folder dalam proyek:**

  ```text
  <MR_RIZZ_VIDEO>
  ├── _projData          <-- Folder Tersembunyi
  ├────── banner.png     <-- Banner dari Projek
  ├────── desc.md        <-- Seperti README.md sebagai tempat menaruh deskripsi proyek
  ├────── _userComment/  <-- Tempat sesi komentar antar user (fitur ini pending, tetapi file tetap dibuat)
  ├── assets/            <-- Gambar, audio, video
  ├── scenes/            <-- File Maya (.ma, .mb)
  ├────── MRZ_sc1_sh1.ma <-- FIle Scene yang dibuat otomatis oleh ProjectCreator
  ├────── MRZ_sc1_sh2.ma <-- FIle Scene yang dibuat oleh user
  ├── scripts/           <-- Skrip pendukung (Python/MEL)
  └── project.db         <-- File metadata/properti proyek terenkripsi + tersembunyi
  ```

## 3. Data yang Disimpan


1. **Medata Dasar**

| Nama Data | Tipe Data | Konten |
|----|----|----|
| Nama Projek | String | MR RIZZ VIDEO |
| Pemilik / Author | String | Stevnich (mengikuti nama pemilik studio) |
| Lokasi Deskripsi Proyek | String Path | \\<currentDirectory>\\_projData\\desc.md |
| Lokasi Banner Proyek | String Path | \\<currentDirectory>\\_projData\\banner.png |


2. **Medata Struktur File dan Folder**

   Pada medata ini, buat group / bagian khusus untuk membuat seluruh daftar file dan folder yang dibuat dalam folder saat ini. ini untuk mitigasi ke user jika daftar file dan folder dalam medata ini tidak sesuai dengan yang sebenarnya didalam folder asli  (misalnya hilang), sistem akan munculkan item file itu dengan latar merah, dan status “Missing!” di daftar file nanti dalam projek. (ini termasuk file scene, asset gambar, skrip, dan lainnya yang ada di lingkup 1 folder ini).
3. **Medata Daftar Tugas**

   Ini adalah indikator yang menentukan seberapa besar atau kecil presentase status proyek, jika semua dicheck, maka status presentase penuh atau sudah selesai. begitu juga saat yang dicheck masih setengah atau belum ada.
4. **Medata Statistik**

   Disinilah data statistik akan dibaca dan tulis oleh sistem, dimana isinya adalah data - data aktivitas yang terekam oleh pendeteksi program maya, dan telah dirangkum oleh sistem. Data ini termasuk:

   \
   
   1. Durasi yang ditempuh tiap file projek
   2. Scene yang dirender dan berapa lama waktu render
   3. Total durasi pengerjaan proyek sejak pertama kali dibuat
   4. Terakhir kali diakses / dibuka
