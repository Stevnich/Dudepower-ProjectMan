# Sistem Pembuatan Proyek

Dalam ProjectMan, Sebuah studio tidak ada artinya jika ia tidak memiliki proyek. Oleh karena itu, di bab ini akan dijelaskan bagaimana sistem pembuatan projek untuk bagian FrontEnd dan BackEnd. Pada proses ini, Studio wajib terlebih dahulu dibuat sebagai syarat untuk membuat proyek.

Setelah pengguna (Anggaplah sebagai studio supervisor) sudah 

* Pengguna tekan tombol "**+ Project**" untuk buat proyek baru ` <Button Classes="btn primary" Click="New_Project">`
* Dialog "**New Project**" akan muncul
* Pengguna akan dimintai beberapa data seperti:

| Property | Type |
|:---|:---|
| Name | TextBox |
| Description | RichTextbox |
| Visibility | DropDown |
| Make Deadline | CheckBox |
| Deadline | DateTimePicker |
| Banner Image | FilePicker |

* Setelah pengguna memasukkan beberapa data, pengguna akan mengklik "**Buat**" untuk mulai membuat proyek, atau "Batal" untuk menutup dialog lalu tidak melakukan apa pun.
