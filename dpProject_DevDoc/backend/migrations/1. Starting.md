# Pengenalan Mengenai Migrasi Studio


1. **Studio / Induk Identitas:**
   * Berisi nama pemilik studio, biodata/identitas pengguna, serta log rekam jejak modifikasi.
   * Menyimpan penunjuk *drive default* tempat proyek disimpan (r).
   * Seluruh metadata studio dienkripsi dan diletakkan di direktori sistem (`%APPDATA%` / `Application Support`) untuk mencegah modifikasi manual oleh pengguna yang tidak berwenang.
2. **Folder Proyek (User Space):**
   * Berada di luar folder sistem untuk menghindari masalah memori, sinkronisasi lambat (*roaming profile*), atau kehabisan ruang disk sistem.
   * Struktur folder dalam proyek:

     \*ibaratkan “***MR_RIZZ_VIDEO****”* adalah folder dari projek*, dan “**MRZ”** adalah kode projek*

     ```text
     <MR_RIZZ_VIDEO>
     ├── _projData          <-- Folder Tersembunyi
     ├────── banner.png     <-- Banner dari Projek
     ├────── desc.md        <-- Seperti README.md sebagai tempat menaruh deskripsi proyek
     ├────── _userComment/  <-- Tempat sesi komentar antar user (fitur ini pending, tetapi file tetap dibuat)
     ├── assets/            <-- Gambar, audio, video
     ├── scenes/            <-- File Maya (.ma, .mb)
     ├────── MRZ_sc1_sh1.ma <-- FIle Scene yang dibuat otomatis oleh ProjectCreator
     ├────── MRZ_sc1_sh2.ma <-- FIle Scene yang dibuat oleh user
     ├── scripts/           <-- Skrip pendukung (Python/MEL)
     └── project.db         <-- File metadata/properti proyek terenkripsi + tersembunyi
     ```

## 3. Alur Kerja Migrasi projek (.projStudios)

Untuk memfasilitasi pengguna yang ingin berpindah OS (misalnya dari Windows ke Mac):


1. **Pengemasan (Export/Package):**
   * Seluruh metadata Studio yang terenkripsi beserta direktori proyek dikemas ke dalam satu file arsip berformat kustom `.projStudios` (berbasis ZIP/Compression).
   * Aplikasi membuat file *manifest* migrasi yang memuat skema lokasi dan struktur awal.
2. **Proses Migrasi & Ekstraksi:**
   * Saat file `.projStudios` dibuka di platform tujuan, aplikasi Project Manager membaca *manifest* migrasi.
   * Metadata Studio diekstrak secara otomatis ke folder sistem tujuan (`AppData` di Windows atau `Application Support` di Mac).
   * Folder proyek diekstrak ke direktori kerja pengguna yang baru.
3. **Smart Path Relinking (Normalisasi Path):**
   * Aplikasi C# secara otomatis menerjemahkan pemisah direktori (Windows `\` $\\leftrightarrow$ macOS `/`) dan melakukan *relinking* pada seluruh *absolute path* proyek agar tidak terjadi kasus *missing assets* atau *broken scene path* saat dibuka di Maya/software 3D.
