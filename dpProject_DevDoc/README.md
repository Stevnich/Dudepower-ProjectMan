# Dudepower Project Manager

Dudepower project manager adalah perangkat lunak untuk memanagemen proyek animasi berskala menengah hingga besar, guna mengatur segala alur kerja proyek mulai dari tahap perancangan hingga tahap publikasi konten.

Tidak hanya sekadar memanajemen proyek, Dudepower project manager juga membantu dalam menganalisis data statistik tentang segala perkembangan proyek dan performa kinerja anda dengan menginspeksi data dari setiap proyek, mendapatkan data dan menghitungnya.

Adapun tujuan dari pengembangan Project Manager antara lain:
* Membantu dalam manajemen aset dalam proyek dan pembuatan proyek
* Menganalisa dan memantau kinerja animator saat bekerja
* Membangun sistem kerja yang cepat dan terintegrasi.

Dudepower Project Manager mendukung platform silang untuk kedua sistem operasi Windows dan MacOS untuk dukungan yang lebih baik. Untuk mendukung pengembangan software untuk kedua sistem operasi tersebut, software dikembangkan menggunakan bahasa csharp (C#) dengan antarmuka AvaloniaUI untuk dukungan multiplatform.
